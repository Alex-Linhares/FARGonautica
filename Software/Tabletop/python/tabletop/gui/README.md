# python/tabletop/gui

The PySide6 GUI: `python3 -m tabletop.gui` (or `tabletop-gui`). Each view is an observer
drawing one of the Qt-free models in [`models/`](models/), and the run waits after every
event until every view has redrawn. Every convention follows the Numbo GUI
(`Software/Numbo/python/numbo/gui/`) through the Seek-Whence GUI
(`Software/SeekWhence/python/seekwhence/gui/`), the closest worked example; the choices the
design leaves open are in [`../../GUI-DECISIONS.md`](../../GUI-DECISIONS.md), one `G-NNN`
each, and the engine's contract for the GUI is
[`../../docs/engine-api.md`](../../docs/engine-api.md).

The engine never imports this package: the engine and the CLI need only the standard
library, and a run gives the same events with or without the GUI (the loop's gate checks
both on every iteration). The GUI drives a run only through `World.step()` on the run
controller's worker thread, reads the world only through `World.snapshot()` and the accessors
engine-api.md lists as drawing nothing, and never touches the run's generator.

**Status: the foundations, the window, the table, the temperature, the Slipnet grid and network, the Coderack, the Worldview and the competitions, the roles (the roles loop's item 14), the trace and event log and the timeline, the controls and the stats, the configuration, sessions and replay, the palette and editor, the results, the help and the command line, the user guide, the screenshots and the READMEs, and the robustness pass (items 00 to 19 of 21).** The package, its
entry point, its packaging, the Qt-free run controller, the tap, the event log, the snapshot
history, the determinism contract, the main window (its docks, menus, layout file and
settings), the icons and the table pane (the objects, the touch and the answer; the groups,
the proposals and the correspondences; the shared selection; the overlays and Eliza's view),
the thermometer, the temperature plot, the Slipnet grid, the Slipnet network, the Coderack
bars and the rack list, the trace and event log and the timeline, the controls and the
stats, the configuration pane, the results, the palette and editor, the help, and session files with their replay exist, and the user guide [`docs/gui/panes.md`](../../docs/gui/panes.md) describes every pane with the pages behind it (item 17; G-055), and the front page's "Using the GUI" section shows the four screenshots that `python3 -m scripts.docs_screenshots` renders offscreen from the quick start's run (item 18; G-056). The robustness pass (item 19; G-058) probes every painting widget's pixels, memory, closing mid-run, the capped run and the smallest window, and made the results pane scroll and the line widgets and the timeline strip cheaper. The final review (item 20; G-059) checked every pane against the design, re-read a sample of 24 citations on the page images, ran every problem of the library through the controller and the window, and is [`docs/gui/review.md`](../../docs/gui/review.md).
