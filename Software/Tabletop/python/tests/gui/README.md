# python/tests/gui

The GUI's tests, after the Numbo GUI's `tests/gui/` and the Seek-Whence GUI's. Run them from
`Software/Tabletop/python/` with `python3 -m pytest -q tests/gui`; the whole suite, engine
and GUI, is `python3 -m pytest -q`, or `bash run-tests.sh`, which runs it in parallel when
pytest-xdist is installed. The GUI's slow tests (the whole runs through the window: the
sessions, the configuration edits, the memory and the capped run, the screenshots, the
window at 1280 x 800) live in `tests_slow/gui/`, one `*_slow.py` file per file here, which
import this folder's helpers and fixtures; `bash run-tests.sh --slow` runs them, `--all`
both suites. The GUI's default tests get about a minute serially; each item records the time
in the loop's PROGRESS.md.

- Qt tests run offscreen under pytest-qt (`conftest.py` sets `QT_QPA_PLATFORM=offscreen` by
  `setdefault`) and start with `pytest.importorskip("PySide6")` and
  `pytest.importorskip("pytestqt")`, so they skip cleanly when PySide6 is missing.
- Qt-free model tests have no such line: they also run in the engine's suite without
  PySide6.
- `conftest.py` gives `golden_runs` (the four golden runs, plain, once per session; G-009);
  `thread_errors` (Numbo's): a test fails if a worker thread raised;
  `window` (Numbo's): a `MainWindow(settings=None)` shown offscreen and closed with its
  worker asserted finished; `module_window`: the same, shared by a module's tests for
  speed; `ini`: a temporary INI for the settings tests. The window fixtures use no default
  layout file (the built-in arrangement).
- **The v2 defaults** (since v3, D-114): the tests that pin a run's facts (an answer, a
  codelet or event count, the moment of a fight, a removal for age) run it on the roles
  engine's a-priori defaults, `V2` and `V2_PROFILES` (`tests/v2_defaults.py`, which
  `golden.py` loads by its path and re-exports, `plain_run(problem, seed, V2)`), so that
  what they check about the panes stays what it was; the tests that compare the GUI with
  the command line, the golden fingerprints or the defaults themselves run `standard`, v3.
