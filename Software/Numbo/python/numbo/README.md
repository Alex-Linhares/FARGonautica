# python/numbo

The Python package. The engine follows the 1987 Lisp file by file and
function by function, with the same names. Each docstring names its Lisp
origin, and each reproduced 1987 quirk has a `# 1987:` comment.

**Engine** (translations of `lisp/src/`; standard library only):

| Module | Lisp origin | What it is |
|---|---|---|
| `start.py` | `start.lisp` | `config`: the set-up phase and the main loop. |
| `init.py` | `init.lisp` | Parameters, `init-chiffre`, `reactivate-cyto`, `refresh-everything`. |
| `codelets.py` | `codelets.lisp` | All 53 codelets and helpers. |
| `cyto_def.py` | `cyto-def.lisp` | The cytoplasm (working memory): four flavors, their methods, `init-cytoplasm`. |
| `pnet_def.py` | `pnet-def.lisp` | The Pnet (long-term memory) as data; its tables are generated by `scripts/gen_pnet_def.py`. |
| `pnet_functions.py` | `pnet-functions.lisp` | Pnode methods, spreading activation, posting codelets. |
| `coderack.py` | `coderack.lisp` | The coderack (reconstructed in the Lisp port). |
| `franz.py`, `flavors.py` | `franz-compat.lisp`, `flavors-compat.lisp` | Franz Lisp built-ins with the oracle's semantics; `send`. |
| `world.py` | `globals.lisp` | The 1987 global environment as a `World` object. |
| `rng.py` | `oracle.lisp` | The shared splitmix64 RNG. |
| `harness.py` | `harness.lisp` | `run_config(problem, seed, max_iterations, ...)`. |
| `solution_checker.py` | `solution-checker.lisp` | Checks the solution printed after "Done :". |
| `__main__.py` | — | The CLI: `python3 -m numbo TARGET B1..B5 [--seed N]`. |

**Observation** (new; not 1987 source):

| Module | What it is |
|---|---|
| `observe.py` | The `Subject`, the `Observer` protocol and the typed events of a run. |
| `events.py` | The hooks that publish the engine's events. |
| `trace.py` | The oracle's JSON-lines trace, written by an observer. |
| `session.py` | Session recording and replay; replaying an SBCL trace with verification. |
| [`models/`](models/) | Qt-free models kept from the events (tree, layout, Pnet, coderack, log, run controller). |
| [`gui/`](gui/) | The PySide6 GUI. |
