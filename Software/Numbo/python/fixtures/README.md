# python/fixtures

Test fixtures **generated by the SBCL port** (oracle mode) and replayed by the
Python tests. Don't edit them by hand. Regenerate them all with:

```sh
python/scripts/regen_fixtures.sh       # from Software/Numbo/
```

Each `NAME.json` is written by `lisp/tests/oracle/NAME.lisp` (with `-` for
`_`); [`lisp/tests/oracle/README.md`](../../lisp/tests/oracle/README.md) says
what each one captures. `python/tests/test_fixtures_current.py` fails if any
of them is out of date.
