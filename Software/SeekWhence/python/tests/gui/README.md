# python/tests/gui

The GUI's tests, after the Numbo GUI's `tests/gui/`. Run them from
`Software/SeekWhence/python/` with `python3 -m pytest -q tests/gui`; the whole suite,
engine and GUI, is `python3 -m pytest -q`, or `bash run-tests.sh`, which runs it in parallel
when pytest-xdist is installed. The four long runs (Blackburn 11 at max speed, the log on
Blackburn 11, the `p146-2` and `fcca-9` presets to their end) are marked `slow` and left out
by default; `bash run-tests.sh --all` or `--slow` runs them.

- Qt tests run offscreen under pytest-qt (`conftest.py` sets `QT_QPA_PLATFORM=offscreen` by
  `setdefault`) and start with `pytest.importorskip("PySide6")` and
  `pytest.importorskip("pytestqt")`, so they skip cleanly when PySide6 is missing.
- Qt-free model tests have no such line: they also run in the engine's suite without
  PySide6.
- `conftest.py` gives `thread_errors` (Numbo's): a test fails if a worker thread raised;
  `window` (Numbo's): a `MainWindow(settings=None, layout_path=None)` shown offscreen and
  closed with its worker asserted finished; `ini`: a temporary INI for the settings tests.
- `golden.py` (not a test file) runs the three appendix runs plain, with Meredith's inputs
  on the golden seeds, as the reference every observer is compared with; `conftest.py`'s
  `appendix_runs` fixture runs them once per session.
