# Problems and seeds for the golden traces (tests/golden/), written by
# chez_scheme/oracle/make-golden.ss.  Format (see make-golden.ss):
#   INITIAL MODIFIED TARGET [ANSWER] | SEED ... | CAP [| keep-going]
# A fourth string makes it a justify run.  CAP is the codelet cap
# (run.ss --max-codelets).  A run ends at the first answer or give-up
# (where the original pauses for Go), at CAP, or if the original halts;
# keep-going runs continue past answers until CAP.  Every run takes well
# under 30 s (most 1-3 s; the longest, 17000 codelets, about 7 s).
#
# Seeds: the seeds documented in chez_scheme/original/demos.ss come first;
# the others (small integers) were added to make 3-5 seeds per problem.
